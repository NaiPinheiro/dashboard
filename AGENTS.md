# Agent instructions

## Agent skills

### Issue tracker

As tarefas deste projeto são registradas e acompanhadas no GitHub Issues do repositório `NaiPinheiro/dashboard`. Consulte `docs/agents/issue-tracker.md`.

### Triage labels

Use a taxonomia canônica `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human` e `wontfix`. Consulte `docs/agents/triage-labels.md`.

### Domain docs

O projeto usa documentação de domínio em contexto único: glossário na raiz e ADRs em `docs/adr/`. Consulte `docs/agents/domain.md`.
