# Issue tracker

## Provider

GitHub Issues.

## Repository

- Owner: `NaiPinheiro`
- Repository: `dashboard`
- Canonical URL: https://github.com/NaiPinheiro/dashboard

## Working agreement

- Registre especificações, bugs e tarefas acompanháveis como GitHub Issues.
- Use o GitHub CLI (`gh issue`) para criar, consultar e atualizar issues.
- Antes de criar uma issue, pesquise títulos e escopo semelhantes para evitar duplicidade.
- Preserve o histórico: prefira comentários e atualizações de estado a apagar registros.
- Pull requests externos não funcionam como superfície de entrada para triagem.
