# Triage labels

| Papel canônico | Label no GitHub | Quando usar |
|---|---|---|
| Precisa de triagem | `needs-triage` | A demanda ainda precisa ser classificada ou delimitada. |
| Precisa de informação | `needs-info` | Falta uma resposta ou evidência indispensável. |
| Pronta para agente | `ready-for-agent` | O escopo está suficientemente definido para execução autônoma. |
| Pronta para humano | `ready-for-human` | A próxima decisão ou ação depende de uma pessoa. |
| Não será realizada | `wontfix` | A demanda foi encerrada intencionalmente sem implementação. |

Uma issue deve usar apenas o estado de triagem que representa sua próxima ação. Ao mudar de fase, remova o estado anterior para evitar classificações contraditórias.
